# 课堂讨论室

基于 TextSync 公共服务器的轻量课堂互动网页。纯单文件 HTML，双击即用，无需安装、无需部署、无任何第三方依赖。

## 文件说明

| 文件 | 说明 |
|---|---|
| `课堂讨论室.html` | 整合版：入口可选教师 / 学生身份，一个文件走天下 |
| `课堂讨论室教师端.html` | 教师端专用（公告管理、消息上屏、提问管理等） |
| `课堂讨论室学生端.html` | 学生端专用（精简界面） |
| `课堂讨论室教师端手机版.html` | 教师端**手机版**：竖屏优化布局，适合 Capacitor 打包成 App |
| `课堂讨论室学生端手机版.html` | 学生端**手机版**：竖屏优化布局，适合 Capacitor 打包成 App |
| `历史版本/` | 重要改动前的备份（v1.1、v1.2、v1.3） |

五个页面功能同构，连接同一房间即可互通。

## 手机版说明

手机版与电脑版**逻辑完全相同**（同一套 JS、同一报文协议，可与电脑端互通），只重做了布局：

- 顶栏单行排列（房间号 / 成员 / 过滤 / 筛选 / 清屏 / 风格转换 / 更多），字号、导出、关于、退出收进「更多」菜单
- 公告编辑合并进输入区：点「公告」后同一输入框切换为公告模式（最多 200 字），发布后自动回到「发言」；公告条只保留展示与「撤下」
- 输入区拆成「类型行 + 输入行」，输入框始终有足够宽度；发送按钮改为「发送」
- 字号默认 16px（电脑版 18px），可在顶栏 A- / A+ 调整
- 采用 `100dvh` + 安全区（刘海 / 底部手势条）适配，触摸目标放大到 36–44px
- Capacitor 打包时直接把这两个文件作为 Web 资源即可（`viewport-fit=cover` 已开启）


## 主要功能

- **实时讨论**：发言 / 提问 / 回答三类消息，教师名带「老师」标识；自己发送后自动滚到最新消息，别人发消息仅在接近底部时跟随滚动（防打扰）
- **富文本**：整条 / 行内文字着色（🎨 色板，选中文字可单独包裹着色）、常用表情；输入时实时预览着色效果
- **图片消息**：全员可发。粘贴（Ctrl+V 或 📋 按钮）、选图直发；大于 2MB 自动压缩；点击图片全屏预览，支持滚轮 / 按钮缩放、拖动、双指捏合、下载
- **文件传输**：全员互传（≤80MB），上传进度实时显示
- **公告**：教师置顶公告，支持着色与富文本；编辑合并进发言输入框——点「公告」进入公告模式（源码编辑、最多 200 字，草稿与发言草稿互不覆盖），发布后自动回到「发言」；公告条无公告时整条隐藏，有公告时可直接「撤下」。迟到者自动补发当前公告
- **问答互动**：学生提问 / 回答带绿色徽标；教师可对任意消息「上屏 / 复制 / 发送到编辑框」
- **筛选与搜索**：工具栏「筛选」一键分类查看——全部 / 问答 / 文件 / 图片；支持多关键词搜索（空格分隔、AND 联合、不区分大小写模糊匹配），匹配词黄色高亮、实时显示匹配条数，与分类查看取交集
- **其他**：成员列表、导出聊天记录、清屏、字号调节、敏感词过滤、本地历史保存（刷新不丢）

## 使用方法

1. 双击打开任意一个 HTML 文件（建议 Chrome / Edge）
2. 输入 **房间号**（5 位，教师端可点「随机」生成合格房间号）与 **姓名**
3. 以教师身份进入需输入 **教师口令**（默认 `1234`，修改口令请改源码中的 `TEACHER_KEY` 常量）
4. 同一房间的师生即可实时互见

## 技术说明

- 纯原生 JavaScript 单文件实现，WebSocket 直连 TextSync 公共服务器；服务器为第三方公共服务，请以「能用多久算多久」的心态使用
- 部分浏览器能力受打开方式影响：`file://` 直开时剪贴板读取每次都会弹授权确认（浏览器安全设计）；部署到任意 `https` 地址（或 localhost）访问则只授权一次
- 聊天历史、最近房间号 / 姓名保存在浏览器 `localStorage`
